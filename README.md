# Print agent (shop laptop)
1. Install Node.js LTS (nodejs.org). Printers must be installed on this laptop and work from Windows.
2. Edit start-agent.bat: replace PASTE_TOKEN_HERE with your AGENT_TOKEN.
3. Double-click start-agent.bat. Leave the window open (put a shortcut in Startup to run on boot).
4. Open the Render admin page > Printers: your printers now appear in the dropdowns. Choose, Save, Print test page.
